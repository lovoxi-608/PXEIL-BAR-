# 花再 Halo PixelBar 歌词投射

把**本地运行的网易云音乐**当前歌词，实时投射到 **漫步者花再 Halo PixelBar 深渊字幕音箱**的像素屏上，内置 8 种字幕播放动画。USB 直连（免蓝牙），歌词与演唱同步。

> 控制页：程序运行后自动打开浏览器控制页（`http://127.0.0.1:8227`），所有操作在页面上完成，仅本机可访问。

## 功能

- **USB HID 直连**音箱像素屏，不需要蓝牙配对（走电脑声卡/有线连接即可）
- **歌词采集走 CDP**（Chrome DevTools Protocol）：从网易云 PC 客户端网页层读取"正在显示的歌词行"，不注入内存、不改文件，网易云升级免疫（选择器不变时无需改动）
- **同步调度**：按网易云官方歌词时间戳（`data-time`）驱动翻页，下一句按音乐时钟**提前预推**，滑动平均校准界面高亮漂移，默认提前 450ms（可在控制页 300~700ms 调整）
- **长句自动分页**：超过屏幕宽度（16 个全角字）自动均衡切分，优先在标点处断开
- **间奏钳制**：自动识别网易云"间奏前一句被计为超长"的时间戳 bug
- **元信息过滤**：作词/作曲/编曲/制作人等行不推上屏幕
- **8 种字幕动画**（见下表）
- **断线自愈**：网易云调试连接被踢、页面重建均自动重连重注入
- **单实例秒开**：重复打开 exe 不会多开，而是直接跳转到已运行实例的控制页（秒开，无需等待重启）
- 退出自动把像素屏恢复为时钟模式

## 快速开始

### 方式一：直接运行 exe（推荐）

从 Release 下载 `花再HaloPixelBar歌词投射.exe`（Windows 10/11 x64），双击运行：

1. 音箱用 USB 线连接电脑并开机（声卡输入模式）
2. 双击 exe，浏览器自动打开控制页
3. 点 **「启动投射」**
4. 首次运行若提示"需要带调试参数重启网易云音乐"，点确定（自动完成，不影响正在播放的内容）
5. **首次使用**：在网易云里打开一次播放页（点击底部播放条的歌曲信息进入黑胶页），歌词组件挂载后，之后切到任何页面都能持续工作
6. 页面可随时切换动画、颜色、翻页提前量；点「停止并恢复时钟」或「退出」，像素屏自动恢复时钟

**运行状态常驻右下角系统托盘**：exe 启动后图标出现在右下角托盘（若被收进「^」隐藏图标区，点开即可看到）。悬停显示运行状态，右键菜单可「打开控制页」或「退出」结束进程。

**网易云程序路径**：若程序自动找不到网易云（或网易云装在非默认位置），在控制页「网易云程序」输入框中粘贴 `cloudmusic.exe` 完整路径并点保存，再点「启动投射」即可。

### 方式二：源码运行

```bash
pip install -r requirements.txt
python main.py
```

## 参数说明

- **翻页提前量**：字幕按网易云歌词时间戳**提前**推送（抵消轮询+USB+固件动画的固有延迟）。默认 450ms。感觉偏早（抢拍）调小，偏晚调大（300~700ms）
- **颜色**：像素屏文字颜色（设备主题色），默认出厂粉

## 常见问题

- **找不到音响设备**：确认 USB 线已插、音箱已开机，点「重新检测」
- **歌词一直不出现**：先打开一次网易云播放页（黑胶页）让歌词组件挂载；确认网易云在播放（暂停时歌词不翻页属正常）
- **无法重启网易云**：在控制页「网易云程序」输入框填写 `cloudmusic.exe` 完整路径并保存，或先手动打开一次网易云再点启动
- **两个软件同时推屏会互相覆盖**：请勿与官方客户端或其他歌词工具同时开启
- 像素屏字库缺字：个别生僻字设备渲染为空白，属固件字库限制
